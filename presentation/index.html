Design Patterns

🔁

Singleton

Tất cả manager sử dụng Singleton + DontDestroyOnLoad để tồn tại xuyên scene

PlayerManager, CombatManager, SaveSystem, UIManager, InventoryManager...
🎯

Strategy + Registry

SkillExecutor đăng ký và dispatch skill qua Dictionary, không cần sửa CombatManager

SkillAction → SwordSkill1..4
EnemySkillAction → ESkill_*
📡

Observer / Event

Buff/Debuff Manager phát event cho UI cập nhật icon mà không coupling trực tiếp

OnBuffApplied, OnBuffRemoved, OnDebuffTick, OnInventoryChanged
📊

ScriptableObject Data

Data-driven design — skill, item, event, icon đều là SO, dễ thêm content mà không code

SkillData, ItemData, EventData, IconLibrary
♻️

Object Pooling

FloatingTextManager tạo sẵn pool 10 text object, tái sử dụng thay vì Instantiate liên tục

FloatingTextManager.ShowText()
🧬

Template Method

Unit.TakeDamage() là base, PlayerManager và EnemyStats override với logic riêng

Unit (abstract) → PlayerManager / EnemyStats

Công Thức Sát Thương

Player → Enemy

1. Evasion Random(0,100) ≤ target.evasion → MISS
2. Crit Random(0,100) ≤ totalCrit + extraCrit → CRIT ×1.5
3. Raw DMG totalAttack × multiplier + flatBonus + typeBonus
4. Final max(1, rawDamage − target.DEF)

Stat Derivation

ATK = base + STR × 0.2 + equip
CRIT = base + DEX × 0.15 + equip
EVA = base + DEX × 0.1 + equip
SPD = base + AGL × 0.5 + equip
HP = 5 + VIT × 1.0 + equip

Phòng Thủ

DEF = baseDEF + equipDEF
Guard = DEF + 1 + ⌊baseDEF × 0.5⌋
Fracture = dmg × 1.30

SEN — Hệ Thống Tinh Thần

Thanh SEN (0 — 10)

10 — 5 An toàn
4 — 1 Nguy hiểm
0 Điên

SEN 5 — 10

  • Hiển thị đầy đủ thông tin quái
  • Sự kiện: Base% + SEN × 3%
  • Bỏ chạy: 80% − senLost × 4%

SEN ≤ 4

  • Icon quái → "???" không rõ
  • Thông tin enemy bị ẩn
  • NPC có thể tấn công / quest thất bại

SEN = 0 — Điên Loạn

  • Madness Panel hiện lên
  • Quay về Town, SEN = 2
  • Mất 50% gold & EXP tầng
Giảm SEN: Mỗi ô dungeon (5%), hết food (16%), bị enemy crit (12%)
Hồi SEN: Thuốc an thần, rượu tại quán, sự kiện đặc biệt

Event & Leveling System

Dungeon Events

📜 Choice Event

2-3 lựa chọn, mỗi lựa chọn có xác suất thành công riêng

Success% = Base% + SEN × 3%
✓ Thưởng: Gold, EXP, HP, Food, SEN, Item, +Stat ✗ Phạt: −HP, −Food, −SEN, −Gold

⚠️ Trap

Không có lựa chọn — áp dụng phạt ngay lập tức

Mất HP, Food, SEN, hoặc Gold

Leveling & Progression

EXP Cần Thiết

EXP = Base(50) + (L−1) × Linear(20) + (L−1)² × Quad(10)

Polynomial: dễ đầu, khó cuối

Mỗi Level Up

+3 Stat Points +3 Max Food Food refilled
